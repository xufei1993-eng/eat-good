# 暖早饮食计划微信小程序

一个面向孕期、减脂和日常健康人群的饮食计划 MVP。当前版本包含首次健康建档、今日三餐计划、食材克数组合、营养进度、拍照/手动确认记录、历史日历和用餐提醒设置。

## MVP 功能边界

- 拍照记录已接入 `cloudfunctions/analyzeMealImage`：上传图片后识别菜品、主要食材、克数和热量，用户可编辑单项热量，确认后才写入记录。视觉结果始终是估算值。
- 营养值为常见可食份量估算，实际值以称重和包装营养标签为准。
- 提醒时间保存在本地。微信订阅消息需要在公众平台申请模板，并配置 `config/index.js` 的 `mealReminderTemplateId`；服务端定时发送仍需后续云函数实现。
- 孕期和慢病风险提示不替代医生或注册营养师的个体化方案。
- 每日能量使用档案中的生理性别、年龄、身高、体重和活动水平进行估算；孕期额外使用孕前体重计算孕前 BMI。计算规则见 `docs/NUTRITION_BASIS.md`。
- 菜谱推荐完全使用本地数据：通用餐在 `data/base-meals.js`，菜系轮换模板在 `data/cuisine-recipes.js`，`utils/local-meal-generator.js` 按日期、菜系和餐次稳定轮换，不依赖云数据库。

## 本地运行

1. 打开微信开发者工具，选择“导入项目”。
2. 项目目录选择本目录。
3. 使用测试号或替换 `project.config.json` 中的 `appid`。
4. 清除本地缓存后重新编译，可体验首次健康建档流程。

## 开通微信登录

在微信开发者工具中部署 `cloudfunctions/auth` 云函数，并在云开发数据库中创建 `users` 集合。小程序启动时会调用 `wx.login`，云函数通过当前请求上下文获取 `OPENID`，自动创建或更新用户记录。无需手机号、密码或单独注册页。

用户表由云函数维护，前端只保存脱敏后的 `authUser` 缓存；如果云函数尚未部署，应用会继续使用本地数据运行。

## 开通照片识别

1. 在微信开发者工具中部署 `cloudfunctions/analyzeMealImage` 云函数并安装其 `package.json` 依赖。
2. 在云函数环境变量中配置 `VISION_API_KEY`；如使用 OpenAI-compatible 服务，可同时配置 `VISION_API_URL` 和 `VISION_MODEL`。密钥不要写入小程序前端。
3. 确认云开发环境已在 `config/index.js` 配置，并允许该云函数访问云存储临时图片链接。
4. 未配置视觉服务时，拍照页面会提示原因，用户仍可使用手动食材估算记录。
