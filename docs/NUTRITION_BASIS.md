# 饮食推荐与档案计算规则

本项目不做诊断或治疗建议。餐品的热量、蛋白质、膳食纤维和价格均按常见外卖份量估算，实际数值以商家标注为准。

## 个体档案计算

- 使用生理性别、年龄、身高和体重，通过 Mifflin–St Jeor 公式估算静息能量。
- 减脂模式再叠加用户选择的活动系数，并应用约 300 千卡的温和缺口。
- 孕期使用孕前体重建立计算基线，自动计算孕前 BMI；孕早、中、晚期分别叠加档案规则中的阶段能量调整。
- 蛋白质目标按体重和模式估算；减脂模式会随活动强度调整。
- 这些结果用于食谱排序、每日进度和建议份量，不是医学处方。未成年人、孕期并发症、慢性病或医生已有方案的用户，应使用专业方案覆盖系统估算。

## 推荐原则

- 优先组合谷薯类、蛋奶豆或肉类、蔬果等不同食物类别，避免早餐只有单一精制主食。
- 先执行孕期风险和过敏原硬过滤，再进行营养评分；不会用高营养分抵消安全风险。
- 早餐、午餐和晚餐使用不同的蛋白质、纤维、碳水比例和钠目标。
- 根据个体每日能量目标调整建议份量，不把低热量作为唯一目标。
- 用全谷物、杂豆、薯类替换一部分精制主食，兼顾膳食纤维。
- 优先蒸、煮等相对清淡的组合，外卖备注建议少盐、少油、少糖、酱汁另放。
- 在达到营养阈值的候选中按日期轮换，减少连续重复。
- 孕期模式先过滤已标记的风险食材；妊娠糖尿病、高血压等情况只生成风险提示和下单备注，不替代医生或营养师的个体化方案。
